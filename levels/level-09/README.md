# Niveau 9 — Recherche d'une valeur dans un tableau

Statut : 🔄 EN COURS

## Énoncé

Demander une taille `n`, remplir un tableau de `n` entiers, puis demander une valeur `x` à rechercher.
Le programme indique si `x` est présente dans le tableau et, si oui, à quelle position (indice).

Exemple :

```text
Entrez la taille du tableau : 5
Entrez les valeurs du tableau :
4 9 2 7 9
Valeur à rechercher : 9
9 est présente dans le tableau, à l'indice 1.
```

```text
Valeur à rechercher : 3
3 n'est pas présente dans le tableau.
```

Pas d'algorithme à écrire avant : écris directement le code C.
