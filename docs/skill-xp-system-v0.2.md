# C QUEST — SKILL & XP SYSTEM v0.2

## COMPÉTENCES
Les compétences sont créées dynamiquement au fil des apprentissages.
Ne pas afficher les compétences encore inconnues.
Les compétences peuvent être divisées en sous-compétences.

- ⭐ découverte/fragile

## RÉÉVALUATION
Une erreur isolée ne fait pas automatiquement baisser une compétence.
Une baisse doit être justifiée par plusieurs observations indiquant une perte importante.
